Small status / label pill for meal-card states, counts and inline meta. For vegetarian / non-vegetarian use `DietBadge` instead.

```jsx
<Badge tone="active" uppercase dot>Active</Badge>
<Badge tone="locked" uppercase>Locked</Badge>
<Badge tone="decided" uppercase>✅ Decided</Badge>
<Badge tone="saffron">3 meals</Badge>
```

Tones: neutral, saffron, active, locked, decided, success, warning, danger, info. Props: `dot`, `uppercase`.
