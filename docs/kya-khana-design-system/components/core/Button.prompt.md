Primary action control for Kya Khana — warm saffron primary with soft, ghost, outline and danger variants in three sizes.

```jsx
<Button variant="primary" size="md">Vote Combo A</Button>
<Button variant="secondary" iconLeft="share">Share list</Button>
<Button variant="ghost" size="sm">Skip</Button>
<Button variant="primary" fullWidth pill iconLeft="check">Confirm</Button>
```

Variants: `primary` (saffron fill), `secondary` (soft saffron tint), `ghost`, `outline`, `danger`. Sizes `sm | md | lg`. Props: `pill`, `fullWidth`, `iconLeft`, `iconRight` (Icon names), `disabled`. Press scales to 0.97.
