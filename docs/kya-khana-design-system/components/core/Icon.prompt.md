Line-icon set (Lucide-derived, 24×24, 2px round stroke) for interface chrome — nav, headers, steppers, actions. Food & diet semantics use emoji (🌿 🍗 ✅), not this component.

```jsx
<Icon name="calendar" size={22} />
<Icon name="clock" color="var(--saffron-600)" />
<Icon name="chevron-down" size={18} strokeWidth={2.5} />
```

Names: home, package, more, calendar, clock, check, check-circle, plus, minus, chevron-down/right/up, bell, share, chef-hat, lock, leaf, search, user, x, arrow-up, refresh, utensils. Inherits `currentColor` by default, so set color via the parent's `color`.
